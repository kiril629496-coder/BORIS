# BORIS Vision

**BORIS** — модульная SaaS-платформа и цифровой сотрудник для автоматизации бизнес-процессов.

## Главный принцип

> Человек не выполняет рутину, человек принимает решения.

## Первый пользователь

Владелец / маркетолог, который управляет 10–20 аккаунтами Авито и хочет с минимальным участием переносить товары и услуги с сайтов клиентов в объявления.

## Первый MVP: Batch System для объявлений

1. Пользователь вводит товар, город, цену, количество.
2. BORIS создаёт пакет объявлений.
3. Пакет можно отправить в очередь публикации, экспортировать или передать в модуль Авито.

## Архитектура

### Core

Пользователи, организации, карточки товаров, ИИ, планировщик, очереди, аналитика, биллинг.

### Executors

Avito, VK, Telegram, OK, Site, CRM.

### AI Agents

- Борис-Директор
- Борис-Авито
- Борис-Маркетолог
- Борис-Аналитик
- Борис-Дизайнер

## Важно

BORIS — не просто автопостер. Это операционная система для публикаций, объявлений, контента и управления площадками.
