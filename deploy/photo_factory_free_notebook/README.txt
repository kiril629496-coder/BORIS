BORIS PHOTO FACTORY — FREE NOTEBOOK WORKER
==========================================

ZERO PAID API
ZERO GPU RENTAL REQUIRED BY BORIS

Public notebook:
https://boris-ai.pro/downloads/boris_photo_factory_free_worker.ipynb

Workflow:

1. On BORIS:
   /root/BORIS/deploy/photo_factory_free_notebook/issue_enrollment.sh

2. Copy the ONE-TIME enrollment code.

3. Open the notebook in a free GPU notebook environment.

4. Turn GPU runtime on.

5. Run notebook cells.

6. Worker sends heartbeat to BORIS.

7. Open:
   https://boris-ai.pro/dashboard/photo-factory

8. Upload REAL references.

9. Create 1-image job.

10. Worker claims one job, generates one image,
    uploads it to BORIS gallery, then stops.

Default free engine:
  SDXL + IP-Adapter

This engine is experimental.
It is intended to prove zero-cost real generation.
The full Qwen worker remains available for larger GPU hardware.
