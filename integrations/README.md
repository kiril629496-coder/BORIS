# Integrations

Модули **внешних интеграций** BORIS SaaS.

## Планируемые интеграции

| Интеграция | Статус | Описание |
|------------|--------|----------|
| [Avito](./avito/) | 🔜 Planned | API Avito для объявлений и сообщений |

## Структура

```
integrations/
├── avito/               # Avito API (в разработке)
│   └── client.py
└── base.py              # Базовый класс интеграции
```

## Принципы

- Каждая интеграция — отдельный пакет с README
- Credentials через переменные окружения
- Retry и rate limiting на уровне клиента

## Добавление новой интеграции

1. Создайте папку `integrations/<name>/`
2. Реализуйте клиент, наследуя `BaseIntegration`
3. Добавьте README и переменные в `.env.example`
