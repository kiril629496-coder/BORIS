BORIS SEO Checkpoint Autofill v1.2.0

Установка / обновление в Chrome:
1. Скачайте ZIP со страницы https://boris-ai.pro/seo-checkpoints
2. Распакуйте ZIP в отдельную постоянную папку.
3. Откройте chrome://extensions
4. Включите «Режим разработчика».
5. Если BORIS SEO Checkpoint Autofill уже установлен:
   - удалите старую распакованную версию ИЛИ замените файлы в её папке;
   - нажмите кнопку «Обновить»/Reload на карточке расширения.
6. Если расширения нет — «Загрузить распакованное расширение» и выберите папку.
7. Обновите https://boris-ai.pro/seo-checkpoints
8. В шапке должно быть: «Расширение подключено · v1.2.0».

RUN 2:
- явные action_url на странице;
- статусы ОТКРЫТО → ЗАПОЛНЕНО → ПРОВЕРЯЕМ → ГОТОВО/LIVE/VERIFIED;
- CAPTCHA batch по 5;
- динамическая плашка «ТВОЁ ДЕЙСТВИЕ»;
- авто resume BORIS после подтверждённого human step.

Безопасность:
- CAPTCHA не решается автоматически;
- Terms/соглашения не принимаются автоматически;
- дата рождения/возраст не заполняются автоматически;
- неподтверждённые адрес/личность не выдумываются;
- коды email/SMS не перехватываются и не заполняются автоматически.
